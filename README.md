# -Diamonds-Dataset-
(Diamonds Dataset) مشروع تحليل بيانات متكامل لتوقع أسعار الألماس باستخدام Machine Learning، شامل استكشاف بيانات، تنظيف، هندسة خصائص، وموديل تنبؤي بدقة R² = 98.15%، مع داشبورد تفاعلي منشور بلينك عام.

وصف تفصيلي (لـ GitHub README أو Portfolio):

مشروع تحليل بيانات (Data Science) شامل يغطي دورة العمل الكاملة على بيانات 53,940 حجر ألماس حقيقي (Diamonds Dataset)، بهدف فهم العوامل التي تحدد سعر الألماس فعليًا، وبناء موديل تعلم آلة دقيق للتنبؤ بالسعر.

خطوات المشروع:

استكشاف البيانات (EDA): تحليل توزيعات المتغيرات، العلاقات بين القيراط والسعر، ومصفوفة الارتباط بين الخصائص الرقمية.
تنظيف البيانات: إزالة التكرارات والقيم الشاذة فيزيائيًا (أقل من 0.4% من البيانات) دون التأثير على القوة الإحصائية للتحليل.
هندسة الخصائص: ترميز ترتيبي (Ordinal Encoding) لمعايير الجودة (Cut, Color, Clarity)، وإضافة متغير حجم مركّب (Volume).
النمذجة: تدريب ومقارنة 3 موديلات انحدار (Linear Regression, Random Forest, Gradient Boosting) — حقق Random Forest أفضل أداء بدقة R² = 98.15% ومتوسط خطأ (MAE) حوالي 269 دولار فقط.
أهم رؤية: الحجم الفيزيائي للحجر (وليس جودة القص كما هو شائع) هو العامل الأكبر تأثيرًا على السعر، بنسبة تفسير تتجاوز 87%.

الأدوات المستخدمة: Python (pandas, scikit-learn, matplotlib/plotly)، Jupyter Notebook، Streamlit، HTML/CSS/JS للداشبورد التفاعلي.

المخرجات: تقرير تحليلي كامل (PDF/Word)، Jupyter Notebook قابل للتشغيل، وداشبورد تفاعلي منشور بلينك عام.
